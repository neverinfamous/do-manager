# DO Manager v1.3.11

## Highlights

- **Hardened Origin & CSRF Defense**: State-changing API calls now enforce strict same-origin or `ALLOWED_ORIGINS` validation, blocking unauthorized cross-site requests.
- **Locked-Down Production Auth**: Local mock authentication is strictly disabled whenever production credentials or Cloudflare Access secrets are configured.
- **Node 26 & Modernized CI**: The Docker runtime upgrades to `node:26-alpine`, and GitHub Actions run on Node 24 releases pinned to `ubuntu-24.04`.

## Changed

- **docker**: Upgraded the multi-stage container base image to `node:26-alpine` and patched bundled `ip-address` to `10.7.6`.
- **deps**: Updated core packages, including Wrangler `4.159`, ESLint `10.14`, Zod `4.6`, TypeScript-ESLint `8.72`, and Cloudflare Workers types.
- **ci**: Upgraded GitHub Actions to Node 24 releases with refreshed commit SHA pins and `ubuntu-24.04` runners.
- **docs**: Added the Docker Hub pulls badge and documented `ALLOWED_ORIGINS` and Zero Trust hostname lockdown settings.

## Security

- **api**: Restricted credentialed CORS headers and `POST`, `PUT`, `PATCH`, and `DELETE` requests to same-origin or configured `ALLOWED_ORIGINS`.
- **auth**: Prevented local mock mode activation when `ACCOUNT_ID`, `API_KEY`, `TEAM_DOMAIN`, or `POLICY_AUD` secrets are present.
- **worker**: Disabled `workers_dev` and `preview_urls` by default in Wrangler configs to eliminate unprotected Worker routes.

## Install

```bash
docker pull writenotenow/do-manager:v1.3.11
```
