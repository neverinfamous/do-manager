# DO Manager v1.3.10

## Highlights

- **Clean Docker Image**: The runtime image now scans with zero known vulnerabilities. Bundled `undici` and `ip-address` are patched.
- **Current Dependencies**: React 19.3, Vite 8.3, and Wrangler 4.155 are in. All open Dependabot alerts are resolved.
- **Safer CI Pipeline**: GitHub Actions are pinned to commit SHAs, so workflow runs stay reproducible.

## Changed

- **deps**: Updated 26 packages, including React, Radix UI, Vite, ESLint, Zod, and Wrangler.
- **docker**: Moved the image build to `pnpm` 11 and copied `pnpm-workspace.yaml` into it. Builds now match the lockfile.
- **ci**: Pinned `checkout`, `pnpm/action-setup`, and `codeql-action` to commit SHAs. Refreshed Docker and gitleaks action pins.
- **build**: Allowed `esbuild` and `workerd` install scripts in `pnpm-workspace.yaml` for pnpm 11.

## Security

- **docker**: Patched npm's bundled `undici` (6.29.1) and `ip-address` (10.7.4). This clears three high and three medium findings.
- **docker**: Updated the pinned `picomatch` to 4.0.7.
- **deps**: Updated `vite`, `undici`, `source-map-js`, and `sharp` past all open Dependabot advisories.

## Install

```bash
docker pull writenotenow/do-manager:v1.3.10
```
